# 👗 Vastra – Clothing Management System

Vastra is a Java-based web application developed using **Spring MVC**, **JSP**, **JDBC**, and **MySQL**.  
The application allows users to manage clothing details with full **CRUD operations** (Create, Read, Update, Delete).

This project is built for learning and practicing **Java Web Development** concepts and follows the **MVC architecture**.

---

## 🚀 Features

- ➕ Add new clothing details
- 🔍 Search clothing by **name**
- 🔎 Search clothing by **ID**
- ✏️ Update clothing information
- 🗑️ Delete clothing records
- 🎨 Responsive UI using **Bootstrap**
- 📂 Clean MVC layered architecture

---

| Layer | Technology |
